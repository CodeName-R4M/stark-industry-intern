# Stark Industry Intern Management System

A Flask web application for managing employee information and access control within Stark Industries.

## Overview
This project serves as an employee management system for Stark Industries, allowing different levels of access based on employee roles and clearances. It provides a secure login system and displays employee details upon successful authentication.

## Features
- Secure login system
- Employee database with role-based access control
- Role-specific employee information display

## Tech Stack / Built With
- Flask
- Python
- HTML
- CSS

## Installation & Setup
```bash
git clone https://github.com/CodeName-R4M/stark-industry-intern.git
cd stark-industry-intern
pip install -r requirements.txt
python app.py
```

## Usage
```python
# Run the Flask application
python app.py
```
